# HN Overseas — website

Public web files for HN Overseas (study abroad consultancy, Lucknow).

| Path | What it is | Status |
| --- | --- | --- |
| `/demo-A/` | Demo A — "The Stamped Passport" design demo | Frozen design demo |
| `/demo-B/` | Demo B — "Departures Board" design demo | Frozen design demo |
| `/demo-C/` | Demo C — "The Kitchen Table" design demo (single-file build) | Frozen design demo |
| `/v1/` | **Production site** — Vite + React + TypeScript port of Demo C | Live |

The production source project is **`hn-overseas-v1-final`** (Vite + React +
TypeScript). Build it with `npm run build` and publish the `dist/` output to
`/v1/`. Demo A/B/C are kept as design references and are not updated.
